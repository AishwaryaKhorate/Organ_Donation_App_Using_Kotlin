# 🫀 Organ Donation App

A simple Android application developed using **Kotlin** and **Firebase** to support the organ donation process. The app allows users to register, log in, and manage donor-related information through a user-friendly interface.

## Features

* User Registration & Login
* Donor and Hospital Modules
* Medical History Form
* Firebase Authentication
* Firebase Database Integration
* Simple and Responsive UI

## Tech Stack

* Kotlin
* Android Studio
* XML
* Firebase Authentication
* Firebase Realtime Database / Firestore

## How to Run

1. Clone this repository.
2. Open the project in Android Studio.
3. Create your own Firebase project.
4. Add your `google-services.json` file to the `app` folder.
5. Sync Gradle and run the application.

## Note

The original Firebase project has been removed, so this repository does **not** include the `google-services.json` file. To run the project, configure your own Firebase project.
